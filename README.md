# 🔮 사주 공부

명리·육임·기문·타로의 개념과 용어를 공부하고, 날짜·시각을 넣어 판을 직접 뽑아 보는 앱이에요.
판 계산은 앱 안에서 하고, 풀이는 칸마다 뜻과 용어를 보여 주는 데까지예요. Claude API 키를 넣으면 판마다 🤖 해석하기(명리·기문 명국)나 🤖 질문에 맞춰 읽기(타로·육임·기문 시가)를 받을 수 있어요.

- 주소: https://kkonoo.github.io/saju_lab/
- 폰에서 **홈 화면에 추가**하면 앱처럼 열려요. 한 번 열어 둔 뒤에는 인터넷이 없어도 열려요.

## 기능

| 탭 | 하는 일 |
|---|---|
| 🀄 명리 · 🔮 보기 | 생년월일시(양력·음력, 윤달 포함) → 원국(십신·지장간·12운성·오행 개수·합충·공망), 대운(순역·대운수), 세운 10년. 📖 일주 풀이(간여지동·괴강·백호·양인·건록 표시). 🤖 해석하기 |
| 🌀 육임 · 🔮 보기 | 날짜·시각 → 천지반·사과·삼전(구종법), 12천장, 둔간, 육친, 공망. 주점/야점, 이전·다음 시. 질문 칸 · 🤖 질문에 맞춰 읽기 |
| 🧭 기문 · 🔮 보기 | 👤 명국: 생년월일시(양력·음력, 윤달 포함)로 원명국·年局·月局·日局을 세우고, 연국에 홍국을 겹쳐 보여 줌(연국+홍국 / 연국 / 홍국). 기본은 연도(年局은 달)·홍국수와 위아래 육친·연국 천반, 나머지(지반·팔문·구성·팔신·대운·소운·유년·12운성·형충·신살)는 칩으로 켜고 끔. 원명국 칸 위에 올해부터 9년(소운), 올해 칸 강조. 생년월일 옆에 나이(세는 나이·만 나이). 사주 줄은 오행 색, 일주를 누르면 풀이. 명리 원국에서 바로 넘어갈 수 있음<br>⏱ 시가 포국: 날짜·시각 → 연국(시가)기문 9궁 포국. 질문 칸 · 🤖<br>글자·표시를 하나씩 누르면 그것만, 칸을 누르면 칸 통째 설명 + 🤖 이 칸 해석하기 |
| 🃏 타로 · 🔮 뽑기 | 원 카드 · 쓰리 카드 · 상황·장애·조언 · 켈틱 크로스. 78장, 역방향 켜고 끄기. 질문 칸(종류·기간·날짜·상대·상황 + 세부 질문, 자주 하는 질문 고르기 — 다 안 넣어도 됨) · 🤖 질문에 맞춰 읽기 |
| 📘 개념 | 과목마다 순서대로 읽는 짧은 글 |
| 📖 용어 | 테마별 용어집, 모든 과목 검색. 본문의 밑줄 낱말을 누르면 그 용어가 떠요 |
| ⚖️ 비교 (명리·기문 보기 안) | 저장한 명리 원국·기문 명국 둘을 골라 표로 나란히 (다른 두 사람, 또는 같은 사람의 명리↔기문). 같은 줄은 흐리게, 🤖 비교해서 읽기 |
| 🧩 사례 | 판 그림 + 단계별 해설 (판은 앱이 계산) |
| 🔧 보정 | 그 과목의 계산 기준과 그 과목만의 설정(타로 역방향 등). 여러 과목에 같이 쓰는 시각 보정·야자시·화면은 ⚙️ |

| 📁 저장한 판 | 이름·메모를 붙여 저장하고 다시 열기 |

## 처음 쓸 때

1. 위쪽에서 과목(🀄 🌀 🧭 🃏 🌱)을, 그 아래에서 🔮 보기 / 📘 개념 / 📖 용어 / 🧩 사례 / 🔧 보정을 골라요.
2. 🔮 보기에서 날짜·시각을 넣으면 판이 나와요. 판의 글자나 칸을 누르면 뜻이 나와요.
3. 💾 저장을 누르면 📁 저장한 판에 들어가요.
4. ⚙️ 설정에서 **시각 보정**(경도 보정 127.5° = 지금 한국 시계보다 30분 늦게 시를 나눔 / 보정 안 함)과 **야자시**를 골라요.

## 계산 기준 (유파마다 다른 부분)

- **절기**: `data/jeolgi.json` (1899~2101). PyEphem으로 태양 겉보기 황경을 구해 만들었고, 천문연 발표 시각과 1분 안쪽으로 맞아요. 다시 만들기: `python tools/make_jeolgi.py`
- **음력**: `data/lunar.json` (음력 1900~2100년). PyEphem 합삭과 절기표의 중기로 무중치윤법(동지 든 달이 11월, 13달인 해는 중기 없는 첫 달이 윤달)을 따라 만들었어요. 천문연 자료(`korean_lunar_calendar` 패키지)와 1900~2050년 모든 날(55,122일)을 대조해 맞췄어요. 날짜 기준 시각은 1911년까지 UTC+8, 그 뒤 UTC+9(1954~61년은 UTC+8:30)예요. 2051년 이후는 계산값이라, 합삭이 자정에 몇 분 차로 걸친 몇 달은 앞으로 천문연이 발표할 값과 하루 다를 수 있어요. 다시 만들기: `python tools/make_lunar.py`
- **시각**: 서울 표준시를 브라우저 시간대 자료로 UTC로 바꿔서(서머타임, 1954~61년 UTC+8:30 포함) 경도로 지방시를 구해요.
- **명리**: 입춘 기준 해, 절입 기준 달. 대운수 = 절입까지 날수 ÷ 3 반올림.
- **육임**: 귀인 甲戊庚 丑/未 · 乙己 子/申 · 丙丁 亥/酉 · 壬癸 卯/巳 · 辛 午/寅, 귀인이 지반 亥~辰에 앉으면 순행. 섭해는 간편법(맹→중→양일 간상·음일 지상). 주점 자동은 卯~申시.
- **기문**: 연국(시가)기문, 전반식, 중5궁은 곤2궁에 기궁. 🔧 보정에서 고름 — 국 정하는 법: 절기중심법(拆補, 기본) / 초신접기(置閏: 상원 부두부터 절기마다 15일, 초신 9일 이상이면 망종·대설에 윤국), 양둔 팔신: 백호·현무(기본) / 구진·주작. 초신접기·구진주작으로 참고 앱과 국·천반·지반·구성·팔문·팔신이 같음.
- **홍국**: 참고 앱 판 다섯 장(1993-01-29 09:00 곤명 원명국·2026 年局, 1992-12-29 12:00 건명 원명국·2026 年局·2026-10-12 日局)과 칸마다 맞춘 규칙 — 홍국수(천간수·지지수 합 ÷ 9, 천반 역포·지반 순포), 世(일지 궁), 육친(世 지반수 기준), 유년(지반 중궁수 궁 괘에서 효 바꾸기), 12운성(世 지반수를 천간으로), 대운(世부터 지반수만큼 순행·천반수만큼 역행, 남녀 같음), 소운(甲子년 남 곤2·여 간8궁에서 순행, 60년마다 처음으로), 국(진극·충 → 沖局, 원진 → 怨嗔局, 가극 → 戰局, 형·해·파 → 刑破害局, 그 밖 和局), 칸 표시(沖·怨嗔·刑·自刑·九金殺, 十은 안 봄), 신살(연지·일지 기준 겁·마·망·연·화 + 일록·천을·천마, 지반수 자리·지지 궁 자리), 일공(○). 年局 달은 월지 궁에 고정. **추정**: 年局 행년(본명성 궁에서 1세 — 1992년생 두 판으로만 맞춤). **아직 없음**: 홍국 팔문(참고 앱 문은 연국 팔문과 다름), 태을구성, 통기, 강약(○X — 첫째 득지·셋째 득령은 맞췄고 가운데를 모름), 기의백격.
- 참고 앱(2026-10-12 10:14)과 대조: 육임 己未日 辰將 巳時 팔전과(卯·午·午)와 천장 배치 일치, 기문 음둔 한로 하원 3국의 천반·지반·구성·팔신 일치(팔문은 홍국 규칙이라 다름).

## 데이터는 어디에

- 저장한 판: 이 브라우저의 IndexedDB `saju-lab` (안 되면 localStorage). 설정: localStorage `saju-lab-prefs` (Claude API 키도 여기에만 있고, 동기화·백업 파일에는 안 들어가요).
- ⚙️ → 💾 데이터에서 백업 파일(`saju-lab-날짜.json`)로 저장·불러오기.
- 로그인하면 Firestore `users/{uid}/saju/{판 id}`에 판 하나씩 올리고, 늦게 고친 쪽이 이겨요.

### 🤖 Claude 읽기 켜기

1. Claude Console에서 API 키를 만들어요. Claude 구독과 따로, 콘솔에 크레딧을 충전해야 해요.
2. ⚙️ → 🤖 Claude → **API 키**에 붙여 넣어요.
3. 판을 뽑고(타로는 카드를 다 뒤집고) 판 위의 **🤖 해석하기 / 🤖 질문에 맞춰 읽기**를 눌러요. 기문·육임은 칸(궁·상자)을 누르면 나오는 창에서 **🤖 이 칸 해석하기**로 한 칸만 읽을 수도 있어요. 질문으로 보는 판(타로·육임·기문 시가)은 질문 칸에 넣은 것만 함께 보내요. 브라우저가 `api.anthropic.com`을 바로 불러요(서버 없음). 읽기는 판과 같이 저장돼요. 저장한 판(📁에서 연 판, 방금 💾한 판)이면 다시 💾 안 눌러도 바로 기억되고, 판을 새로 뽑거나 날짜·시를 바꾸면 지워져요. 🔄 다시로 다시 읽을 수 있어요.
4. 모델(`claude-opus-5-5`)은 `js/reading.js`의 `askClaude`, 과목마다 읽는 방식(프롬프트)과 판을 글로 바꾸는 부분은 `AI`에 있어요.

### 구글 로그인 켜기

1. Firebase 프로젝트는 `saju-lab-29`예요. 설정값은 `js/firebase-config.js`에 들어 있어요(다른 프로젝트로 바꿀 때만 고쳐요).
2. Authentication → Sign-in method → Google 사용, 승인된 도메인에 `kkonoo.github.io` 추가.
3. Firestore Database 만들기 → 규칙 탭에 `firestore.rules` 내용을 붙여 넣고 게시.

## 내용 고치기

- 용어·개념·사례는 `data/<과목>.json` (base · myeongri · liuren · qimen · tarot). 형식은 `tools/SCHEMA.md`.
- 본문 안 `[[mr-sipsin]]`, `[[mr-sipsin|십신]]`은 용어 링크가 돼요.
- 고친 뒤 `python tools/validate.py`로 id 중복·없는 링크를 확인해요.
- 사례 판 값 확인: `node tools/dump-cases.js`
